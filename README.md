# Projeto JavaScript

Este projeto contém um exemplo simples em JavaScript.

## Descrição

O arquivo [index.js](index.js) está configurado para executar uma mensagem inicial do tipo "Hello, World!".

## Estrutura do projeto

- [index.js](index.js) — arquivo principal com a lógica atual do projeto
- [README.md](README.md) — documentação do projeto
- [desafio.md](desafio.md) — referência do desafio

## Como executar

Abra o terminal na pasta do projeto e execute:

node index.js

## Resultado esperado

A saída do programa será:

Hello, World!

## Tecnologias

- JavaScript
- Node.js
