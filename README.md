# Desafio do Felipão

Este projeto foi desenvolvido para resolver o desafio clássico do Felipão da DIO: classificar o nível de um herói com base na quantidade de experiência (XP).

## 🧩 Objetivo

Crie uma função que recebe o nome e a quantidade de experiência de um herói e retorna uma mensagem informando o nível em que ele se encontra.

## 📊 Regras de classificação

- Ferro: menos de 1000 XP
- Bronze: 1001 a 2000 XP
- Prata: 2001 a 5000 XP
- Ouro: 5001 a 7000 XP
- Platina: 7001 a 8000 XP
- Ascendente: 8001 a 9000 XP
- Imortal: 9001 a 10000 XP
- Radiante: 10001+ XP

## 🏗️ Estrutura do projeto

- `index.js` — arquivo principal com a lógica do desafio
- `README.md` — documentação do projeto
- `desafio.md` — referência do enunciado do desafio

## ▶️ Como executar

1. Abra o terminal na pasta do projeto.
2. Execute o comando:

```bash
node index.js
```

## 💡 Exemplo de saída

```bash
O Herói de nome "Mestre dos Codigos" está no nível de Platina
```

## 🛠️ Tecnologias

- JavaScript
- Node.js

## 📝 Observação

A lógica principal deve ser implementada no arquivo `index.js`, conforme a regra de classificação do nível do herói.
